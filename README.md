## 🇫🇷 Présentation
Cache-toi sous les voitures sur ton serveur FiveM RP.
Approche un véhicule, glisse-toi dessous, observe au ras du sol, puis ressors en toute discrétion.

🎥 **Vidéo :** [LIEN YOUTUBE]

### ✨ Fonctionnalités
- Glisse-toi sous les SUV, berlines et sportives
- Animation fluide, allongé sur le dos
- Caméra réaliste sous le châssis
- Sortie discrète
- Léger et optimisé
- Configurable via `config.lua`

### 📥 Installation
1. Télécharge le script (bouton **Code → Download ZIP**)
2. Place le dossier `kx_souscaisse` dans `resources/`
3. Ajoute dans ton `server.cfg` :
ensure kx_souscaisse

4. Redémarre ton serveur

### ⚙️ Configuration
Tous les réglages sont dans `config.lua`.

## 🇬🇧 Overview
Hide under cars on your FiveM RP server.
Walk up to a vehicle, slide underneath, watch from ground level, then sneak back out.

🎥 **Video:** [YOUTUBE LINK]

### ✨ Features
- Slide under SUVs, sedans and sports cars
- Smooth lying-on-your-back animation
- Realistic under-chassis camera
- Discreet exit
- Lightweight and optimized
- Configurable through `config.lua`

### 📥 Installation
1. Download the script (**Code → Download ZIP**)
2. Put the `kx_souscaisse` folder in `resources/`
3. Add to your `server.cfg`:
ensure kx_souscaisse

4. Restart your server

### ⚙️ Configuration
All settings are in `config.lua`.
